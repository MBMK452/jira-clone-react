# Task Manager (Jira Clone)

A full-stack, relational project management application inspired by Jira. Built to demonstrate secure API architecture, relational database management, and dynamic state handling in a modern React application.

**Live Demo:** https://jira-clone-react-caqjuou45-mbmk452s-projects.vercel.app/

## 🚀 Tech Stack
* **Frontend:** React (Vite), Axios, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas, Mongoose
* **Authentication:** JSON Web Tokens (JWT), bcryptjs
* **Deployment:** Vercel (Frontend), Render (Backend)

## ✨ Key Features
* **Secure Authentication:** Complete user registration and login system with password hashing and JWT validation.
* **Relational Data Models:** Complex database relationships connecting Users to Workspaces, and Workspaces to Tasks.
* **CRUD Operations:** Full ability to create, read, update, and delete tasks dynamically.
* **RESTful API:** Clean, protected backend routes handling business logic and database queries.
* **Cloud Deployed:** Fully hosted infrastructure with separated client and server environments.
